# 引火生气盲派 · 实战断盘手册

> 依据：6296 例逐例判读校准（甲木 616、乙木 738、丙火 577、丁火 683、戊土 675、己土 534、庚金 458、辛金 615、壬水 495、癸水 460、2021 新增 445 检验集）。
> 版本：v2.0。凡本书所引例号，均可回《×册判读全编》原处复核。
> 用法：拿到一个盘，从第一篇往下走，不许跳步。跳一步，后面全错。

---

## 使用说明：这本手册是什么，怎么用

这不是一本讲道理的书，是一本**操作手册**。每一节都按同一个格式写：

| 栏 | 含义 |
|---|---|
| **动作** | 眼睛该往哪儿看 |
| **判据** | 看到什么算什么 |
| **例号** | 凭什么这么说（可回原处复核） |
| **错断** | 这里最容易错成什么样 |

三条使用铁律：

1. **不许跳步。** 九步链是单向的，② 家里家外判错，后面全错；③ 根基出处没找到，④ 体用就是空的。
2. **不许由象直推身体。** 见冲就说「有伤」是外行。冲只担保「动」，伤在哪由所冲之字主何事定。
3. **不许无标记下断。** 每条判据后面都标着「验过几次、在什么条件下失效」。没有标记的断语，不许拿来断人。

# 第零部分 · 结论先行（输出模板）

断盘的第一段文字，不是推演，是**结论**。先把答案摆出来，再讲为什么。读者要的是判断，不是过程。

## 0.1 一页纸格式（照填）

```
【格】  ××格，成／成中有破／不成
【身】  旺／弱／从，坐基如何，调候有无
【用神】×（一句说清它管什么）
【喜】  ×、×
【忌】  ×（最忌）、×
【层次】上／中上／中／中下（一句：靠什么立身）
【六域】 财：… ／ 官职：… ／ 婚：… ／ 子：… ／ 亲：… ／ 健康：…
【关键运】最顺：×运（约×岁）；最困：×运（约×岁）；转折：×年、×年
【一句话】一句能记住的总纲
```

## 0.2 写结论的三条规矩

1. **先给方向，后给量级。** 「富格，中上；财源在食神，不在财星」——先方向（富），再量级（中上），再机制（食神）。
2. **每条结论后面挂一个判据或例号**，不许空口。挂不上判据的，就不写进结论区，降到「待验」。
3. **不确定的写「不足以判」，不写「大约」。** 同盘异命、学历、应期年份，这三处最容易含糊，宁可留白。

## 0.3 结论先行 ≠ 只给结论

结论段之后，仍要走完十步链，逐条把判据摆出来。**结论给方向，推演给凭据。** 只给结论是算命，只给推演是炫技，两者都给才是断盘。

# 第一部分 · 用盘前三查

三查不过，不许下断。这是全流程的第一道闸，也是最容易被跳过的一道。

## 1.1 定盘

**动作**：核对公历／农历、早子晚子、交节临界。

| 查什么 | 怎么查 | 错了会怎样 |
|---|---|---|
| 公历与农历是否对应 | 用万年历反查，年柱以**立春**为界，不以元旦、不以春节 | 年柱错则大运起法全错 |
| 月柱是否过**节** | 以节令（立春、惊蛰、清明…）为界，不以月中 | 月令错则旺衰判反，九步链第①步即崩 |
| 子时归属 | 23:00 后属次日早子，须换日柱 | 日柱错则体用全错 |
| 交节临界 | 生于交节前后一两小时者，须核真太阳时再定 | 临界盘最易错，且错得最隐蔽 |

**体检记录中常见的硬错**（本套判读共查出 60 余处，随手可举）：
- 月柱与公历不合：#4182（月柱己亥与 1976-09-23 不合，当为酉月）。
- 时柱与生时不合：#3921、#4187。
- 23 时后未换日：#4207。
- 年柱与生年不合：#4241（1538 与癸卯年不合）。
- 生于海外未校时差、南半球未改月柱：#6199、#6180。

## 1.2 定时

**动作**：按出生地经度做真太阳时校正。

| 项 | 算法 | 备注 |
|---|---|---|
| 平太阳时 | 北京时间 ±（当地经度 − 120°）× 4 分钟 | 每 1° ＝ 4 分钟 |
| 均时差 | 另加，最大约 ±16 分钟 | 精密定盘时才计 |
| 临界处理 | 校正后落在时辰边缘的，两个时辰都要试判，取与已知事实相符者 | 两盘都断一遍，不许只挑一个 |

**为什么必须做**：错一时辰，时柱全变，而时柱是「家里」与「事类」的落点。本套判读中，#6295 临潼造经度校正后可能由亥时落入戌时，若改甲戌，则全盘只剩两亥，「三亥伏吟」这条主断必须重写——**一个时差，结论反向**。

## 1.3 体检（剔盘）

**动作**：先剔不可用之盘，再谈命中率。

| 病症 | 判据 | 处置 |
|---|---|---|
| 同盘异命 | 四柱全同而层次、事实全异 | **只计一次论证**，不许硬找时辰变量 |
| 重复录入 | 四柱、生时、出生地、正文全同 | 合并计一次 |
| 同盘异运 | 四柱同而大运不同 | 可作「运决层次」的旁证，但须拆开判 |
| 日主混入别册 | 册名与日主不符 | 单列，不计入该册 |
| 正文缺失 | 无实录、无生辰、只有标签 | 只判格局，不对账 |
| 层次标签可疑 | 标「中产」而做工是巨富（#5125） | 按做工判，不按标签判 |

**同盘异命是本套体系最硬的一道边界**，必须记住这几组：

| 组 | 四柱 | 两人 |
|---|---|---|
| #4768 / #4773 | 庚戌 丁亥 辛巳 庚寅 | 华罗庚（数学家、政协副主席）／临沂警察、中专 |
| #5259 / #5284 | 戊辰 癸亥 壬午 丙午 | 明建极殿大学士／房产靠父母的小康职员 |
| #4789 | 壬子 壬子 辛卯 辛卯 | 资产数亿之商人／厅级干部／古人进士（三人同盘） |
| #5214 / #5197 | 同八字 | 厅级官／五十亿商 |
| #5061 / #5067 | 同八字 | 武警少校／平凡孤苦 |
| #5073 / #5072 | 同八字 | 古例科甲县令／普通职员 |

**处置规矩**：遇四柱全同者，一律只计一次论证。**不许**为了解释差异去调时辰、找方位、编「同盘不同命」的玄谈。盘面不足以判的，就写「盘面不足以判层次」。

# 第二部分 · 九步链逐步操作

顺序即纪律，不许跳步、不许倒序。

```
① 定旺衰 → ② 分家里家外 → ③ 寻根基出处 → ④ 分体用 → ⑤ 找做工
→ ⑥ 比力量 → ⑦ 定格局 → ⑧ 断职业 → ⑨ 走运
```

## 第一步 · 定旺衰

**动作**：只看四个位置——月令（最大）、时支（第二旺点）、年支与日支（弱点）。

| 位置 | 权重 | 说明 |
|---|---|---|
| 月令 | 最大 | 决定当令之神，也决定格 |
| 时支 | 第二 | 常是「家里」的落点，改事类不改量级 |
| 年支、日支 | 弱点 | 但日支是自身坐基，日支一根一病常是百倍之差（#1897 对 #1900） |

**判据**：得令、得地、得生三者占几项，定为旺、偏旺、中和、偏弱、弱、极弱。极弱者**先辨从格**。

**从格的辨认（必须先做，否则后面全反）**：
- 身无本气根、无印生、满局一气 → 从。例 #4775（壬子 辛亥 辛亥 辛卯，水旺成势、身无金根、无印）从儿，食伤生财而富；#4789（壬子 壬子 辛卯 辛卯）从儿，三人同盘而皆富贵取向。
- **从与不从会随运而变**：#4785 辛酉运比劫得禄，身得根，**从格回反**为「泄太过」之病，此运应肾病垂危。这是本套判读里最容易被忽略的一条。

**错断**：
- 只数五行个数，不看位置权重 → 月令被当成普通一支。
- 见身弱就补，见身旺就泄，不问「能不能任」。
- 忘了先辨从格，把从格当身弱断，一路断反。

## 第二步 · 分家里家外（全链的轴）

**动作**：给每一个字贴标签——**年月＝家外**（社会、国家、别人），**日时＝家里**（我、配偶、团队、资源）。

**判据**：

| 字落在 | 归谁 | 断什么 |
|---|---|---|
| 年柱 | 家外、祖上、大环境 | 别人家的、体制的、远处的 |
| 月柱 | 家外、父母、同辈 | 可得但需手段，不必然入手 |
| 日支 | 我家、配偶宫、坐基 | 我的、贴身的 |
| 时柱 | 我家、子女宫、下属、成果 | 我的产出与归属 |

**这一步错了会怎样**：同一个字，落在年柱是别人的，落在时柱是我的。这一条不改，后面全错——**财在年月而无一字合我者，看得见拿不到**（#5512、#5521、#5536、#5538 对 #5525）。

**错断**：
- 见财就断富，不问财在谁家。
- 见官就断贵，不问官根在家在外（#4480 丙禄在日支巳＝在家→大贵；#4473 丙官透时干而根全在两巳＝家外→有官不任职）。

## 第三步 · 寻根基出处

**动作**：每一个透出的天干，找出它的根落在哪个地支。根在哪柱，决定它归谁。

**判据**：

| 根的情况 | 断法 |
|---|---|
| 通根本气（禄、长生、帝旺） | 有力，可任 |
| 只通余气、墓库 | 力薄，须运补或冲开 |
| 无根（虚透） | 只主「名」，不主「实」（#4798 丙正官虚透坐子无根，靠戊印有根代官而成职） |
| 根在家外 | 事在外，我须伸手去取 |
| 根在家内 | 事在我家，我自然得 |

**三条硬规矩**：
1. **同五行第二根同时被冲者，视同孤根**（#4893 卯本有未库为第二根，然未同时被月支丑冲，两根俱动，转伤成立）。
2. **合去唯一根，与冲同效；合主陷，冲主击**（#3166 辰酉合去唯一土根应水厄）。
3. **合化会连根带干一起化掉**：#4823 巳申合化水，日支巳中丙官本气与申中戊印根俱化 → 有婚无职；#4833 寅亥合化木，寅中丙官唯一根与戊印根俱化 → 志大才疏。

**错断**：
- 只看天干不看根 → 把虚透当实有。
- 只找一根，不查「第二根有没有同时被打」。
- 忘了合化能把根化尽（这是最隐蔽的一类，见第四部分 §4.9）。

## 第四步 · 分体用

**动作**：把全局分成两堆。

| 体（我取物的工具） | 用（一生所求） |
|---|---|
| 印、食伤、比劫 | 财、官杀 |

**判据**：体是用以取用的工具。体强用弱 → 有力无处使；用强体弱 → 有物无力取（身弱不胜财官，见财官反成压力）。

**特例（重要）**：**职不必由官星**。官只是「用」的一种。无官者任一级上将、统帅、首辅、教授、副市长、掌财政者，十余例（#3294、#3340、#3342、#3390、#3611、#4795 副市长、#4800 园长、#4733 元首）。故第四步只分体用，**不许把「无官」判成「无职」**。

**错断**：见无官即断平民，见无财即断贫——两断皆废（见第三部分铁则②、⑬）。

## 第五步 · 找做工

**动作**：找这个盘在「干什么活」。只看六种：生、克制、合、冲、夺、开库。

| 做工 | 机制 | 关键 |
|---|---|---|
| 生 | 食伤生财、印生身、财生官 | 看有无去向，去向断则空转 |
| 克制 | 食伤制杀、印克食、官克身 | **制杀之败，凶在制不在杀** |
| 合 | 合定归属、合化变质 | 合不必然解冲；合去根与冲同效 |
| 冲 | 冲主动、唯一根被冲则转伤 | 只担保「动」，不担保「伤在哪」 |
| 夺 | 比劫夺财 | 须财现日时＋劫有根＋财根唯一 |
| 开库 | 刑冲为钥，六合为锁 | 库是阀门，只判「何时动、向谁开」 |

**最容易漏的三种做工**：
1. **合化把制神化掉**——不见冲、不见克，制神却没了。#5377 时支寅（食禄）与日支戌半合火，食神被化，制路自废；#5079、#5080、#5250 同型。
2. **害**——申亥害、子未害、卯辰害，非冲非合，条外漏判多由此出（#4203 申亥害而九岁夭折、#5390 申亥害而心脏病起）。
3. **伏吟**——刃、禄、日支伏吟之年亦应凶，与冲独立计算（#4119 癸酉车祸、#4519 三丑叠伏吟而亡）。

**错断**：只找冲，不找害与伏吟；只找克，不查合化；见合就以为解了冲。

## 第六步 · 比力量（含「到家直接得」的四个前置）

**动作**：比体与用的力量。体＞用 → 拿得到；体＜用 → 拿不到且有灾。

**但先查「到家」这条路**：财官已到家里、我又有手段 → **不看力量，直接得**。而「到家」必须过四道前置，缺一即不得：

| 前置 | 判据 | 反证 |
|---|---|---|
| ①财透干或有合路引出 | 不透不见，无合路不入手 | #4832 双卯财旺而刑破局→工薪三千；#4829 财藏日支不透→下岗负债 |
| ②局不被刑破 | 刑冲破了局，有等于无 | #4832 |
| ③不被旺水漂 | 水多木漂 | #4829 三壬成党 |
| ④身有根可任 | 身无根则得而守不住 | #5032、#5042、#5075、#5076 三前置齐备而身无根→贫寒不聚财 |

**旁通路径（v0.9 补，很重要）**：妻财官印可由**六合、刑冲开库、合化**牵进我宫，**不透干亦可得**。
- #4942 财藏年支午、不透，亿级；#4944 千万级。
- #5208 子丑合把官印合入我宫 → 正厅。
- #5359 寅午合、#5355 丑戌刑、#5350 丑未冲、#5370 巳申合 —— 皆大富。
- **有合路即不看库锁**：#5686 财全锁戌库，却以甲己合杀、借土（田宅）成十多亿。

**错断**：#4950 财官同藏日支戌、卯戌合路成立，直断大发，实录仅科级——**判过头**。

## 第七步 · 定格局

**动作**：把做工归入九格之一，并标出「成格／破格／成中有破」。

| 格 | 成立条件 | 破了会怎样 |
|---|---|---|
| 官来护印／印来化杀 | 官印相生，身能任 | 印被合化则官无引 |
| 枭印夺食 | 印透克食，且官杀真引动 | 食有实根则夺不尽，只成内耗 |
| 食伤生财 | 食伤有根＋财有去向 | 无去向则才成而路窄（#5417 账房、#5411 僧人、#5393 术士） |
| 食伤制杀 | 制神有根 | **制路三废：根绝、被合、被化** |
| 食伤泄秀 | 身有根可任泄 | 身无根则泄身成病 |
| 伤官见官 | 伤官旺而官有根 | 女命主婚变 |
| 伤官配印 | 印能制伤而不克尽 | 印制太过则秀路断 |
| 财制印 | 财旺克印 | 印为学历之旧说已废，看泄秀 |
| 比劫夺财 | 财现日时＋劫有根＋财根唯一 | 财在家内者劫反为我用 |

## 第八步 · 断职业

**动作**：只问两件事——**财官落谁家**、**我取财官的手段是否与家里家外都发生关系**。

| 结构 | 职业 |
|---|---|
| 官根在家、有制有承 | 公职（吃国家饭） |
| 财库在家、有手段伸向该库 | 自己当老板 |
| 财在年月、我无引路 | 给私人老板打工 |
| 食伤生财而财归我位、身能任 | 技术入股、自营 |
| 制杀成格 | 强力部门（军警、执法） |
| 印重无泄 | 文教、学术 |
| 食伤无去向、身无根 | 体力糊口 |

**错断**：见官断官、见财断商。职业由「财官落谁家＋手段」定，不由单个十神定（#4795 官杀全无而副市长两届）。

## 第九步 · 走运

**动作**：大运是背景，流年是事件。

**三步**：
1. **定主角**：流年干支是谁、根在哪、与局中哪个字同气。
2. **断做工**：这个字引动了什么（冲、合、害、伏吟、开库）。
3. **判归属**：引动的是谁的事（所冲所合之字主何事）。

**四条定则**：
- **冲只主动，凶在动到了什么**（#5262 冲午而财不伤，却摇动午中己官，应夫亡）。
- **伏吟同冲**（#4119、#4519、#4174）。
- **害同冲**（#5390、#4203）。
- **库开只判何时动、向谁开**，不判多少；开而身不能任则成灾（#6239 丑戌刑开财库，愈得愈欠至负债三百万）。

**错断**：见冲断凶、见合断吉。冲合只定「动」，吉凶须再问身能否任、制是否有根。

## 第十步 · 定喜忌用神

**动作**：不另起炉灶，**从前面五步（做工）与第七步（格局）倒推**。用神不是一个孤立的字，是「让这个盘的做工能转起来的那个五行」。

### 10.1 四步倒推法

| 步 | 问什么 | 怎么答 |
|---|---|---|
| ① 看做工缺什么 | 这个盘在干什么活？干到哪一步断了？ | 例：食神生财，但食神被印克 → 断在「食」 |
| ② 看格局靠什么成立 | 成格的关键字是哪个？ | 例：食神生财格，关键在丙火不受伤 |
| ③ 定用神 | 谁能补上这个断口？ | 例：护丙者——木生火、火自身得根、燥土制水 |
| ④ 排喜忌 | 用神为轴，分四层 | 喜＝护用神者＋调候；忌＝破用神者；仇＝帮忌神者；闲＝无关 |

### 10.2 四种取用法，按优先级

| 法 | 何时用 | 取什么 |
|---|---|---|
| **病药** | 盘中有明病（一字被克、被合、被冲而伤） | 治这个病的字 |
| **调候** | 生于寒冬（亥子丑月）或炎夏（巳午未月） | 寒用火、燥用水；调候常优先于扶抑 |
| **通关** | 两强相战（如水火、金木对峙） | 能通两气之字（水木火、金水木） |
| **扶抑** | 无明病、无寒燥、无战争 | 旺则泄／克／耗，弱则生／帮 |

**优先级**：病药 ＞ 调候 ＞ 通关 ＞ 扶抑。盲派重「做工」，故病药与调候最常先手。

### 10.3 喜忌四层的写法

```
用神：×（一字，说清它管什么）
喜神：×、×（护用神者；调候之物；制忌神者）
忌神：×（最破用神的那一个，必须点明「最」）
仇神：×（帮忌神的）
闲神：×（无关，不必论）
```

### 10.4 用神落运（这一步决定「哪十年最顺」）

把七步大运逐一对用神称重，贴三档：

| 档 | 判据 |
|---|---|
| **喜运** | 运干支生扶用神、或用神得禄得库、或去忌神 |
| **忌运** | 运干支克用神、或助忌神成局（如三合、三会） |
| **平运** | 一喜一忌相抵 |

**关键提醒**：**合局比单字更重**。一支忌神不可怕，三合成局才可怕——申子辰成水、寅午戌成火、亥卯未成木、巳酉丑成金。看运先看它有没有把局合成。

### 10.5 错断

- **见身弱就补、见身旺就泄**，不问做工断在哪 → 用神取反。
- **只取扶抑，漏调候** → 冬夏之盘全错（子月甲木无火，补多少水木都是寒）。
- **用神取「缺什么补什么」** → 缺的不一定是用神，可能正是该缺的。
- **用神与格局脱钩** → 断出「用神是财」而格局是食神生财，等于没说。

# 第四部分 · 分域断法

每一域给一条**判据序列**（按顺序走，不跳），加正反例号，加该域的专属陷阱。

## 4.1 层次

**序列**：
1. 先剔同盘异命（§1.3），盘面不足以判的，直接写「不足以判」。
2. 看②家里家外：财官是否到家。
3. 看③根基：根在家还是在外。
4. 看⑥力量：身能否任。
5. 看日时全同否：若同，先比年月透干之克合，再论时支。

**三层粗断**：
| 层次 | 结构特征 |
|---|---|
| 上（权贵／巨富） | 财官到家、有制有承、局不被刑破；或从格成势而无破 |
| 中（小康／中产） | 财官到家而力量不足，或到家而有一破 |
| 下（平凡／贫薄） | 财官在家外而无引路；身弱不胜财官；制路废而杀攻身 |

**专属陷阱**：
- **四柱全同而层次差极大者，不许硬解**：#4768/#4773（数学家对警察）、#5259/#5284（大学士对小康职员）。
- **标签不可信**：#5125 标「中产」而做工是巨富，按做工判。
- **日支一根一病，常是百倍之差**：#1897 对 #1900（年干月支日干时柱全同，仅日支戌／申之别，千万与十万）。

## 4.2 职业

**序列**：财官落谁家 → 我取财官的手段 → 制杀成不成格 → 印重不重 → 食伤有无去向。

| 断语 | 结构 |
|---|---|
| 公职 | 官根在家、有制有承；或印有禄根代官 |
| 自营 | 财库在家且有手段伸向该库 |
| 打工 | 财在年月、我无引路 |
| 强力部门 | 制杀成格（军警、执法） |
| 文教术业 | 印重无泄 |
| 技艺糊口 | 食伤无去向、身无根 |
| 演艺／身段取财 | 食神生财而食禄被冲被克（#5380） |

**专属陷阱**：见官断官。**#4795 官杀连藏干俱无而副市长两届；#4800 官杀全无而幼儿园园长；#4733 刘少奇无官杀而至元首。**

## 4.3 财富

**序列**：
1. **透**：财透干否（显隐）。
2. **通**：有无合路／冲开／库路把财牵进日时（归属）。
3. **任**：身有根可任否。
4. **局**：局被刑破否、被旺水漂否。
5. **夺**：劫有根而财根唯一否。

| 断法 | 结构 | 例号 |
|---|---|---|
| 大富 | 财透＋通＋身能任 | #5308 双丙透坐午根→四百亿；#5567 丙财透时＋辰戌冲库→77 亿美元 |
| 富而薄 | 财透而不通 | #5396、#5398、#5415、#5416 位高财薄 |
| 贫 | 不透不通 | #5320 财锁戌库负债二百万；#5330 搓背为生 |
| 漂（透而不通必漂） | 财透无根、被旺水围、坐水库湿土 | #5754 三亥夹一丁；#5760 丁坐亥；#5780 丙坐辰；#5790 |
| 富而不固 | 食伤旺而财根被刑合 | #5600 |
| 无财而富 | 财星全无，靠印重主土／合杀取财 | #4039 四五十亿房产商；#5197 五十亿；#5686 十多亿 |

**专属陷阱**：**财星有无不作判据**（铁则⑬）。见无财断贫、见财多断富，两断皆废。

## 4.4 学历（全书唯一系统性短板，须格外小心）

**序列（四步，缺一不可）**：
1. **根**：食伤有无本气根／禄。
2. **去向**：财透干，或财根立，或六合旁通引出。
3. **库**：食伤闭库者，看运补（运透食伤或冲库）。
4. **破**：食禄被冲、被克、被合化者，断。

| 结果 | 条件 | 例号 |
|---|---|---|
| 高 | 根实＋去向通 | #5138 状元硕博；#4948 博士；#4953 研究生 |
| 低 | 根实而无去向 | #4949 小学；#4969 小学二年级；#5281 文化极低；#5359 初二；#5376 十五岁打工 |
| 低 | 食禄被冲被克 | #5380 初中（寅申冲＋庚克甲）；#5385 不识字 |
| 低 | 根被合化 | #5693 食神随卯戌化财→三类本科须花钱 |
| 需运补 | 闭库 | #5134 戊戌运冲辰开库→厅级／双博士 |
| **给不出结论** | 食伤全无而印旺身旺 | #5819 徐志摩（顶尖学历）；#5514、#5616、#5628、#5689、#5705 反向 |

**三条硬提醒**：
1. **食伤全无而印旺身旺，只作加分项，不作判据**。这是 v1.0 定死的，独立检验集里 20 例失手全在这一条上。
2. **同盘异运须拆「运前／运后」两段判**（#5580 同一盘早年辍学、后段因印透读到研究生）。
3. **学历与财路是两条独立的线，可并存**（#5380 学历初中，同年入百万）。

## 4.5 婚姻

**序列**：夫／妻星落谁家 → 配偶宫（日支）被什么动 → 官杀混杂否 → 财（妻）是否被合出我宫 → 伤官见官否。

| 断语 | 结构 | 例号 |
|---|---|---|
| 妻随人走／私奔 | 妻星（日支或财）被合出我宫 | #5388 日支午合时支戌，乙酉年妻私奔 |
| 婚变 | 夫宫被冲、伤官见官、官杀混杂 | #4226 寅亥合走夫宫→得财不得夫 |
| 不婚／婚迟 | 财星连藏干俱无（只主婚迟，不主无婚） | #1448 等十例反证 |
| 夫亡 | 官根被冲兼伏吟 | #4765 两亥冲巳，辛巳年夫亡 |
| 婚姻和睦 | 官有根、宫不被合冲 | #4798、#4800 |

**专属陷阱**：**见无官断无夫、见无财断无婚，两断皆废**（C 级）。女命无官杀者，财被合入我家时夫星可由财代偿（#1446）。

## 4.6 子女

**序列**：子星落在哪（男看官杀／女看食伤）→ 根是否立 → 是否被冲 → 是否被克尽 → 子女宫（时柱）被何占据。

| 断语 | 条件 | 例号 |
|---|---|---|
| 无子 | 子星全无，或根被克尽 | #3857、#4117、#4268 |
| 有子而损一 | 食有根而印克之（夺不尽则损） | #4801 两子而一胎夭折 |
| 子多 | 食伤旺而有根 | #4771 两子 |
| 无子而反有二子 | 子星无根而妻星成 | #4112、#4382（本条降 B 的两端） |

**专属陷阱**：本条两端皆不稳，**不许单凭子星下断**，须与妻（夫）星、身之能否任合看。

## 4.7 六亲

**序列**：找星 → 看是否被夹（两侧合冲克）→ 看星之根 → 看宫位。

| 六亲 | 星 | 宫 | 断法 |
|---|---|---|---|
| 父 | 偏财 | 年／月 | 星被夹则应灾；不现则缘薄 |
| 母 | 正印 | 年／月 | 印透而虚则母缘薄；印被冲则母有灾 |
| 兄弟 | 比劫 | 月 | 比劫坐财则争；比劫受冲则兄弟有灾 |
| 配偶 | 官杀（女）／财（男） | 日支 | 见 4.5 |
| 子女 | 官杀（男）／食伤（女） | 时柱 | 见 4.6 |

**关键判据**：**六亲之断看「是否被夹」，不看星之强弱**（B 级）。星旺而独透者，六亲多无恙；星弱而被两侧气夹住，即应。

**例**：#5389 母（辛正印）透而坐亥无根、父（偏财丙）不现 → 八月丧母、五岁丧父；#5385 印三重透而母位被巳申合动 → 少年母丧。

## 4.8 健康（只指系统，不指病名）

**序列**：找最受伤的五行 → 看它代表何系统 → 看冲它的是什么 → 定发作之年。

| 五行 | 系统 |
|---|---|
| 木 | 肝胆、筋、目 |
| 火 | 心、小肠、血脉、目 |
| 土 | 脾胃、肌肉 |
| 金 | 肺、大肠、皮毛、骨 |
| 水 | 肾、膀胱、生殖、耳 |

**判据**：
- 五行被克尽、且为唯一泄秀／生身之根者，成重疾（#4718 食神唯一根被克尽→肠癌、骨癌）。
- 火受伤而火在年柱（头面）者，应目疾（#5391 丙火被克被合→两眼 0.3）。
- 水火相战而身无根者，应肾与血（#4785 泄太过→肾病）。
- **害同冲**：申亥害而害禄，心脏起病（#5390）。

**专属陷阱**：**不许由冲直接推病名**。凡见「冲某支必患某病」之断，一律退回「哪一行受伤、属何系统」。

## 4.9 应期与凶灾

**序列**：定主角（流年干支根在哪）→ 断做工（引动了什么）→ 判归属（是谁的事）→ 判吉凶（身能否任、制是否有根）。

**四类应凶的引动**：
| 引动 | 机制 | 例号 |
|---|---|---|
| 冲 | 冲唯一根、冲身根、冲开杀库 | #5390 申亥害；#4207 子午冲 |
| 合 | 合去唯一根（合主陷） | #3166 辰酉合去土根→水厄 |
| 伏吟 | 刃、禄、日支、库伏吟 | #4519 三丑叠伏吟而亡；#4119 车祸 |
| 害 | 申亥、子未、卯辰 | #4203 九岁夭折 |

**三组合断（最凶的年，通常是三样同时到）**：
- **制路废 ＋ 库开 ＋ 杀透** = 大凶年：#5387 壬戌运戊子年，制神被克废、丑戌刑开杀库、戊杀透 → 车祸两命、刑拘。
- **财生杀 ＋ 身库被冲** = 死期：#4786 壬辰运甲戌年，甲财生丁杀、戌冲辰开库 → 患癌冬亡。
- **伏吟 ＋ 杀透** = 被擒／大厄：#4787 丁卯运丁丑年，丁杀再透、丑伏吟日支 → 被抓获。

**专属陷阱**：**应期不编年份**。只给「何运何年、引动何字、应何事」，不许把公历年硬套上去（除非原档已载）。

# 第五部分 · 三十条常见错断

每一条都是这 6296 例里真实踩过的坑，按「错在哪 → 正确做法」写。断盘前过一遍，能省掉大半返工。

## 一、关于官与职

1. **错**：见无官即断平民。**对**：官只是「用」的一种，无官亦可任高职（#4795、#4800、#4733）。
2. **错**：见官有根即断有职。**对**：须「根在家、有制有承」，三者缺一则职不显（#3849、#4069、#4714）。
3. **错**：官合身即断废职。**对**：官有根、有印引、有财局承托者不废职（#4247 连跳三级）。
4. **错**：见官虚就断无职。**对**：印有禄根可代官根（#4798 丙虚而戊印有根→得校长）。
5. **错**：见官杀混杂即断必凶。**对**：官杀混杂而身能任、有印化者，反可承（#5528）。

## 二、关于财与富

6. **错**：见无财断贫。**对**：财星有无不作判据（#4039、#5197、#5313）。
7. **错**：见财透断富。**对**：透只定显隐，通才定归属（#5396、#5415）。
8. **错**：见财库闭断无财。**对**：库只锁所有权（#2133、#2508）。
9. **错**：见财透无根不断灾。**对**：透而不通必漂（#5754、#5760、#5780）。
10. **错**：见劫多即断破财。**对**：须财现日时＋劫有根＋财根唯一，财在家内者劫反为我用（#4630）。
11. **错**：见冲开财库即断发财。**对**：库开只定动，须身能任（#6239 愈得愈欠）。
12. **错**：见财被合即断财尽。**对**：有旁通合路则复通（#5686 甲己合杀取土成十多亿）。

## 三、关于学历

13. **错**：见印旺断高学历。**对**：「印＝学历」整条废除（#1525 印三会而小学）。
14. **错**：见印弱断低学历。**对**：同上，#1498 印坐死而博士。
15. **错**：见食伤旺断高学历。**对**：须有去向；无去向者才成而路窄（#4949、#5281）。
16. **错**：见食伤全无即断低。**对**：印旺身旺者可高（但只作加分项）；本体系在此类**给不出结论**时，如实写「不足以判」。
17. **错**：一盘一次判完学历。**对**：同盘异运须拆运前／运后（#5580）。

## 四、关于冲合与伤病

18. **错**：见冲断有伤。**对**：冲只担保动，伤在哪由所冲之字主何事定。
19. **错**：由冲直推病名。**对**：退回「哪一行受伤、属何系统」。
20. **错**：见隔位冲即断无力。**对**：所冲为唯一根者，隔位亦转伤（#3966、#3886）。
21. **错**：见合即断解冲。**对**：合只改归属，不改存亡（#4226）。
22. **错**：只找冲与合。**对**：害（#4203）、伏吟（#4519）、合化（#5377）都是漏判重灾区。
23. **错**：见身旺即断冲不伤。**对**：身旺而所冲为我所用之财时不转伤；但冲仍摇动同宫之物（#5262 财不伤而夫亡）。

## 五、关于制杀

24. **错**：见杀旺断凶。**对**：凶在制不在杀（#3994、#4973）。
25. **错**：只查制神有无。**对**：查三废——根绝、被合、**被化**（#5377 寅戌合火，食禄化尽而不见冲克）。
26. **错**：见制旺断吉。**对**：制路过旺亦成祸源（#5534 入伤官运反革职、#5547）。

## 六、关于子息与六亲

27. **错**：见无官杀断无子。**对**：子星降 B，两端皆不稳（#4112 无官而两子）。
28. **错**：见星弱断六亲有灾。**对**：看是否被夹，不看强弱。
29. **错**：见同盘即找时辰变量解释。**对**：四柱全同者只计一次论证（#4768/#4773）。

## 七、关于层次

30. **错**：按标签判层次。**对**：按做工判（#5125 标「中产」而实为巨富）。

# 附录 C · 这套体系的边界（必须知道的四件事）

1. **学历是唯一系统性短板。** 独立检验集 445 例中，32 例失手有约 20 例在学历。原因是学历一半由盘定（泄秀之根）、一半由时代与家境供给。**判学历时语气要收，宁写「中低」不写「必无」。**

2. **同盘异命是硬边界，不是软解释。** 四柱全同而层次悬殊者，至少六组。凡遇此，只计一次论证，直接写「盘面不足以判层次」，不许编方位、编时辰、编玄谈去圆。

3. **从格随运而变。** 身无根而一气成势者为从；一旦行比劫、印运，身得根即**从格回反**，原先的用神立刻变成病神（#4785）。判从格必先问：这一步运，身得不得根。

4. **应期能定「何运何年、引动何字、应何事」，不能定具体公历年。** 除非原档已载年份。凡把公历年硬套上去的，十个有九个是事后凑。
