## v0.1 · 2026-10-18（依据：甲木 616 例 + 乙木 738 例，共 1354 例）

### 一、分级建立

初次把底本《体系·生气木》的判据拆为三级。原始体系无权重、无失效条件，直接照用必然自相矛盾。分级依据如下。

**升 A 级（已复验）10 条**，各有 3 例以上独立支撑，其中：

- 子卯刑主头面之伤：甲木 #53（96 年脑溢血）、#60（2008 车灾、2020 脑瘤两次开颅）、#548（右眼残）、#560（头痛后右眼失明）。四例独立，症状全落头面。
- 官虚透降级：甲木 #14（合同制收费员、无编制）、#6（杀无根而只求财）、#17、#64（体育特长入外贸局为合同工）。
- 闭库无财：#16（辰酉合闭辰库，穷得只有一条裤子）、#39（三戌无冲，负债二十万）、#544（两戌无合无冲，终身租房）、#363（辰辰并见不冲，买房须借）。
- 枭印夺食分级：#4（两壬克丙 → 口吃自闭，大学后好转）、#20（壬坐申有力 → 贫穷到底）、乙木 #681（癸克丁 → 抑郁、不能自理）、#692（兼巳亥冲 → 刀刃入胸）。
- 冲刑分工：甲木 #325（戊寅年偏瘫）、#333（甲戌年跌伤）、#332（双寅双申车亡），皆岁运补成三刑方应灾；单冲无一例成灾。
- 制杀之败凶在制不在杀：乙木 #1300（丁壬合去食神，杀成局无制而亡）、#1071、#1073（制神悬空，止于中层武职）。
- 劫财夺产：甲木 #58（2015 拆迁兄弟反目）、#21（妻出轨、净身出户）。

**降 B 级（有条件）6 条**，其中最要紧的是「印＝学历」：

- 正例：甲木 #6（子印在时坐旺 → 本科）、#51（壬印在时坐申长生 → 硕士）、乙木 #1153（日支丑中癸得酉生）、#1155（时支子为旺点）。
- 反例：甲木 #17（癸坐丑有根而小学四年级）、#31（印三见而小学四年级）、#42（壬癸两见而无学历）、#54（无水无印而本科）；乙木 #207（壬印透时坐申长生而小学）、#1100（无印而博士）、#1117（印浮月而研究生）。
- 结论：只在「家里坐下之印且坐旺」时成立，其余一律不可用。

**废 C 级（已证伪）6 条**，领头的两条：

- **「无官星不做官」**：甲木 #10（无官星而仕至番臬）、#52（三造无官而黄堂、富翁、省牧）、#55（无官而副处）；乙木 #625、#632、#633、#641、#643（无官而成疆臣、尚书、侍郎、厅级、副部）、#1200、#1206、#1207。合计逾八例，反证充分。处置：遇「官杀本无」，此条整条作废；只有「官存在而被坏」才谈降级。
- **「同八字必同命」**：甲木 #52（三造同盘，结局三途，原文自陈“一交庚戌三造同亡”）、#136（同村同柱，一有编制一务农）、#167·#178（辛弃疾盘与当代房产销售）；乙木 #750·#762、#1165·#1170、#1307·#1321。处置：体系只定节律，不定量级。
- 其余：神煞断人品、量级断言（刑期/官品/子女数/财额/寿数）、以命断病名、以貌断贵贱，均废。

### 二、本轮新增的方法论条款

1. **旺点互战优于旺衰**：月令与时支两个旺点直接对冲，即判全局失守，不必再论日主强弱（乙木 #542 两子冲一午、#566 子午冲加子卯刑）。
2. **时支单独比**：年月日相同者，须单列时支对比。乙木 #1115 与 #1118 前六字全同，仅时支申/午之别，一为硕士教师有房有车，一为职高未毕业、电切割、欠债。
3. **制化两途定层次**：同一杀，走「化」（印）者得位而不显功，走「制」（食伤）者得功而必带劳伤，制化俱无者落残、囚、贫（甲木 #301 与 #321 同为杀重印化却一为团级一为赤贫，差别在杀从哪条口出去）。
4. **火根被拔主神明之病**：丙丁落亥子或被水围克，主神志、血脉（乙木 #1249、#1251 同机制互证，分别 19 岁、14 岁发病）。

### 三、数据体检结果（决定命中率能否计算）

1354 例中，明确的数据硬伤 **60 余处**，分四类：

- 同盘异命 / 正文重复错配：甲木 #29·#37、#136；乙木 #621·#623、#641·#643、#750·#762、#858·#865、#911·#919、#1023·#1032、#1030·#1033、#1027·#1034、#1165·#1170、#1307·#1321、#1323·#1329。
- 日主混入他册：甲木 #195、#291；乙木 #793。
- 四柱与公历/时辰自相矛盾：甲木 #179、#187；乙木 #691、#703、#709、#766、#871、#1144、#1342。
- 古例无行实（只能判格局，不能对账）：各册均有。

**结论**：这些样本须在统计命中率前扣除，否则任何“准确率”都是虚的。

### 四、待观察（进 B 级观察区，等后续册数验证）

- 「卯戌合锁禄 → 婚姻受制」在体弱/体旺两造上分岔（乙木 #1337 与 #1354）。
- 「六亲看是否被夹」是否可推广至父母、子女（现仅兄弟、母两组）。

## v0.3 · 2026-10-18（依据：丙火 577 例，累计 1931 例）

### 一、废除（1 条）

**「印＝学历」整条废除。** 证伪例累计十九例：

- 丙火册新证：#1443（甲印坐午死、又被寅午合化 → 高二辍学）、#1498（印坐死地而博士）、#1500（印坐禄而十五岁辍学）、#1525（印三会成局而小学）、#1541（两甲坐死而南开）、#1540（甲浮年而研究生）、#1524（甲坐死而本科）、#1862（双印各有实根而职高）、#1870（甲旺而退学）、#1871（乙通根未库而初中）、#1838（乙透根在辰而三本）、#1906（无印而博士）、#1895、#1910（印坐财库而初中）。
- 前两册：#17、#31、#42、#54、#207、#1100、#1117、#1572。
- 正证仅存四例：#6、#51、#1861、#1848。

处置：遇学历一律写「盘面不足以判学历」，不得由印之有无强弱直推。原 B 级窄版（家里坐下之印）亦一并作废——丙火 #1524、#1541 正是“坐下之印而坐死”的反例。

### 二、修订（2 条）

1. **「冲之叠加转伤」加前置「根不孤」**。反证四例：#1802、#1812、#1825、#1827——所冲之字另有根（双寅、双戌、双午），冲只主动不转伤。正证十五条（#1496、#1511、#1582、#1589、#1593、#1564、#1590、#1635、#1646、#1799、#1807、#1810、#1917、#1928、#1931）。改写为：单冲主动；所冲为唯一根、或冲合成局者转伤；叠加须先验根孤。
2. **「库闭则钱在账上」降为 B 级**。#1841 财仅戌中一辛、终身无冲而应千万；#1687 辰酉合锁库而能赚不能守、屡聚屡散。改：库闭只锁所有权，不锁进项。

### 三、新增（4 条，其中 1 条直入 A 级）

1. **A 级｜印坐刃可解刃冲**。#1902（甲印坐午刃，子午冲而仕途平顺）对 #1886（四子冲午早夭）、#1882（午年冲子触电横死）、#1914（子午冲加子卯刑入狱）。四例成组，前置检查清晰：刃上坐印否。
2. **B 级｜层次不只看时支，日支一根一病亦定层次**。#1897 与 #1900 年月日干时柱全同，仅日支戌（火库为根）/申（病地、巳申合去禄根）之别，千万与十万之差。
3. **B 级｜透干定主，支中引字定局**。#1863（癸透、亥支，应父横死）对 #1864（同支而癸藏不透，只断平淡）。
4. **B 级｜三刑齐本身不主凶**。#1906（三刑齐而博士）对 #1892（三刑齐而枪决）。吉凶看刑开何库、身能否任。

### 四、观察区（进 B，等后续册数）

### 五、方法论警告（本册最重要的一条）

丙火 #1795–#1834 片的判读员在收尾时写下一句，须全文录入本引擎：

> **命中率 85% 不可采信——四十例皆自带结局与层次标签，属古例选编，只能证链能走通，不能证断得准。**

这与甲木 #52 的三造同盘、乙木多组同盘异命互相印证。任何“准确率”，须先扣除同盘异命与错配样本，并在**未见结局的新盘**上另做检验。否则统计的是“解释力”，不是“预测力”——两件事，不可混。

## v0.4 · 2026-10-18（依据：丁火 683 例，累计 2614 例）

### 一、降级（2 条）

1. **「官杀得根才有一职」：A → B**。三组反证与四条替代路径：
   - 反证 #2537、#2550、#2559：官根皆落日支亥、官杀成局，而终身不任公职，以自营或打工为生。共同点：丁无火根、印不能化杀。
   - 替代路径一：**印有禄根可代官根**（#1937 两癸坐巳卯无根而副市长、#1950 官仅藏子而国企在编、#1968 壬坐寅虚而公务员、#2074、#2086、#2088、#2066）。
   - 替代路径二：**官藏库得根亦算**（#2074、#2086 官全藏辰丑而得正处；#2184 辰中癸余气不作虚透）。
   - 替代路径三：**运补**（#1410、#1411）。
   - 另加一条否决：#2605 官得余气根却无编制，因官合身——**应婚不应职**。
   - 又：#1991、#2005 官杀有实根而身不能任，根反为灾，故论职须加「身能任」。
2. **「财库被六合锁 → 有钱拿不出」：绝对版废除**。丁火册八例反证（#2133、#2142、#2378、#2404、#2508、#2522、#2486、#2471），皆锁库而不缺进项。改：锁只锁所有权，不得断无财。

### 二、修订（3 条）

1. **「冲转伤」再加两前置**：
   - **无通关**：#2128 巳亥冲、亥为官之唯一根，财旺通关，冲只主动，一生平顺（状元、军机大臣）。#2595 卯为唯一印根，双酉夹冲，应的是挪用公款获刑而非体伤——**印通关者不转体伤**。
   - **伤指所主之事，不限身体**：#2607 冲唯一禄根，只应贫寒劳损、一婚和气；#2595 冲印而应官非。
   - **先辨所冲是身之根还是印之根**：#2303 寅申冲、寅为甲禄即印根而官坐申得长生，一冲一调而官至市长；#2324 卯为丁唯一生身之神，冲则残腿。#2299、#2330 寅亥合解冲，只主调动。
   - **「根不孤」须加“双根各有生助”**：#2379 双卯并列、同处无生助，被单酉一冲俱伤，十岁母亡、终身凶死。
2. **「时支定层次」加前置：先看年支有无泄路**。#2412 与 #2438 月日时全同、均为火局劫比成群，唯年支一为木库（有泄）、一为火（助旺），一瘫一教授。时柱全同而层次悬殊者，先比年支。
3. **「刃位随流派」须声明**。丁之刃，一派在未（禄前一位）、一派在巳。判「印坐刃解刃冲」前必先声明所用刃位，否则同一盘可得出相反结论。

### 三、新增（2 条）

1. **A 级｜子星看是否被制，不看旺衰**。#2508（戊制壬而多年无子，庚子年官到得子）、#2526（己制壬而妻不孕）、#2517（子酉双破而无子）。男命以官杀为子，食伤制官则伤子。
2. **B 级｜虚财不受夺**。劫财夺财须先有可夺之财：财坐绝、根虚者，劫虽有根亦夺不成（#1967 丙劫月上有根而辛坐亥无根，一婚平顺、财不散）；#1949 己土居中通关，火生土、土生金，夺势被化。故「劫财夺财」须加「财有根」与「通关或合护」两前置。

### 四、本轮再证（不升不降，只增例证）

## v0.5 · 2026-10-18（依据：戊土 675 例，累计 3289 例）

### 一、降级（1 条）

**「时支定层次」：A → B，改为「只在年支泄路相同时才可比」。**

- 正证仍多：戊土 #3018/#3034（同年月日、差两小时，一处级子女一低保）、#3061/#3065、#3176/#3177（顶流对外包）、#3259/#3274、#3255/#3256。
- 反证：#2845/#2847（年月日全同，仅时支午／子，层次同为平凡而婚、子、财全异）、#2884/#2888（时柱同为丁巳，一大专一小康、一文学宗师寿百零五）、#2928/#2934（四柱与时柱全同，一电信主任一纸品厂老板）。
- 处置：年月日相同时先比年支泄路，再比时支；时柱全同而层次全异者，按同盘异命处理，**直书「盘面不足以判层次」**。

### 二、改写（3 条）

1. **「印坐刃解刃冲」→「刃上有解即不凶，印与合皆可解」**。戊土 #3254 子先合丑而冲解、身体安然；#3231 无合无印则断臂；#3241 刃上坐日主而非印，冲之应自身官非。新增边界：解的是刃凶，不解印星本身被冲（#3121 丙坐午而庚子运子冲午，母亡）。
2. **「合优先于冲」→「合定归属，不必然解冲」**。反证 #2870（子丑合未解子午冲，该年仍受重伤）、#2861（子丑合只减冲力）、#2713、#2724。
3. **「劫财夺财」→ 条件为「劫有根」，位置只定轻重**。#2875、#2882、#2894 三例劫在日时而财在年，位置与原说相反仍应夺财夺妻；#2659 三戊成群而掌经济权、无夺产，须加「财现于日时」。

### 三、补充前置（2 条）

1. **「冲转伤」再补三条**：
   - **紧贴**：#3005 卯酉隔位冲，卯为乙官唯一根而无通关，按条应伤婚与子息，实录婚好二子。
